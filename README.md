
# Kabarin 

Kabarin is a mobile news app built with Flutter. It makes it easier to read the latest news from different categories in one place.

Users can browse news, explore articles, and save their favorite stories to read later. Kabarin also provides Dark Mode and Light Mode for a more comfortable reading experience.

## Features

- **Home** – View the latest headlines and featured news.
- **News Categories** – Browse articles by category.
- **Explore** – Discover and read more news.
- **Bookmarks** – Save articles to read later.
- **Dark & Light Mode** – Switch between themes across all screens.
- **Pull to Refresh** – Refresh the page to get the latest news.

## Built With

- Flutter
- Dart
- Riverpod
- Material Design

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Go to the project directory:

   ```bash
   cd news_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Theme

Kabarin has two theme options:

- **Dark Mode:** Dark background with white news cards and dark text.
- **Light Mode:** White background with black news cards and white text.

The selected theme is applied across all screens.
